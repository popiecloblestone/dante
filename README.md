# Morfologia — Laboratório Interativo de Solos

Apresentação interativa baseada no estudo fornecido, com registros de dois perfis de solo de Gurupi.

## Abrir

Abra `index.html` em um navegador atualizado. Todos os recursos de exploração funcionam localmente e não exigem instalação. Os links de mapas abrem serviços externos.

## Explorar

- Arraste o bloco de solo para girar. Os botões + e − ajustam a aproximação.
- Use “Separar camadas” para visualizar os três horizontes separadamente.
- Clique em uma camada, nos botões de horizonte ou percorra o controle deslizante para atualizar a ficha.
- Alterne entre Perfil 1 e Perfil 2.
- Em “Comparar”, arraste a divisão entre as fotografias e selecione os horizontes.
- Em “Campo”, selecione os dois pontos do diagrama.
- “Apresentar” inicia um roteiro de oito etapas. Use as setas ou os controles na tela; Esc encerra.

## Conteúdo

O modelo tridimensional e o diagrama de localização são esquemáticos, sem escala métrica. As amostras de cor são ilustrativas; as notações Munsell e demais atributos foram transcritos do documento original.

O material repete a profundidade 20–43 cm para os horizontes AB e B do Perfil 1. O site preserva esse registro e sinaliza a necessidade de conferência.
